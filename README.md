# Tsuki Sushi 🌙 — ระบบสั่งอาหารผ่าน QR ที่โต๊ะ

เว็บไซต์ร้านซูชิ + ระบบสั่งอาหารเองที่โต๊ะ (QR Ordering) + หน้าจอครัว + แคชเชียร์
HTML + CSS + JavaScript + Bootstrap 5 (ไม่ต้อง build) · ฐานข้อมูล **Supabase** · โฮสต์ด้วย **Vercel**

| | |
|---|---|
| แบรนด์ | **Tsuki Sushi** (สึกิ = พระจันทร์) · *ซูชิสดใหม่ ใต้แสงจันทร์* |
| โทนสี | อินดิโก้กลางคืน `#151a33` · แดงตราประทับ `#e0323c` · ทอง `#e8b45a` · กระดาษวาชิ `#f8f4ec` |
| เมนู | 36 รายการ · 8 หมวด (ซูชิ มากิ ซาชิมิ ข้าวหน้า ทานเล่น เส้น ของหวาน เครื่องดื่ม) |

## หน้าจอทั้งหมด

| URL | สำหรับ | ทำอะไร |
|---|---|---|
| `/` | ทุกคน | หน้าร้าน: เมนูทั้งหมด วิธีสั่ง ข้อมูลร้าน |
| `/login` | พนักงาน | เข้าสู่ระบบ (Supabase Auth) |
| `/host` | **ทุกคน** (ไม่ต้องล็อกอิน) | **① กรอกเลขโต๊ะ + จำนวนคน → ได้ QR** พร้อมพิมพ์/คัดลอกลิงก์ |
| `/menu?t=…` | **ลูกค้า** | **② สั่งอาหาร** — เมนูพร้อมรูป ตะกร้า หมายเหตุถึงครัว ดูสถานะ เรียกเก็บเงิน |
| `/kitchen` | ครัว | **③ หน้าจอครัว** — ออเดอร์เรียลไทม์ + เสียงเตือน กดรับ/เสิร์ฟ เตือนออเดอร์ค้าง |
| `/cashier` | แคชเชียร์ | **④ ชำระเงิน** — ดูบิล ส่วนลด รับเงิน (สด/พร้อมเพย์/โอน/บัตร) ทอนเงิน พิมพ์ใบเสร็จ |
| `/admin` | แอดมิน | ภาพรวมยอดขาย · จัดการเมนู · บิลย้อนหลัง · โต๊ะ · พนักงาน · ตั้งค่า + Telegram |

### รายละเอียดที่คิดมาให้แล้ว
- **โต๊ะเดียวเปิดซ้อนไม่ได้** — unique index กันพนักงานเปิดซ้ำ
- **QR หมดอายุเอง** — token ใช้ได้เฉพาะตอนโต๊ะยังเปิด ปิดบิลแล้วสแกนเดิมไม่ได้
- **สั่งเพิ่มได้หลายรอบ** — แยกเป็นรอบที่ 1, 2, 3 … ครัวเห็นเป็นคนละใบ
- **ของหมด** — แอดมินปิดสวิตช์ เมนูเทาในหน้าลูกค้าทันที สั่งไม่ได้
- **ออเดอร์ค้างนาน** — การ์ดในครัวกะพริบแดงเมื่อเกิน 12 นาที
- **ตะกร้าไม่หาย** — เก็บใน localStorage แยกตาม token ปิดจอ/รีเฟรชแล้วยังอยู่
- **ยอดเงินคำนวณที่ฐานข้อมูล** — แก้ราคาจากฝั่ง browser ไม่ได้

## เริ่มใช้งาน

### 1. ตั้งค่า Supabase
อ่าน [`supabase/README.md`](supabase/README.md) — สรุป: รัน `supabase/schema.sql` → เอา URL + anon key ใส่ `assets/js/config.js` → สร้างบัญชีพนักงาน (คนแรก = admin)

### 2. รันในเครื่อง
```
npx serve -l 5173 .
```
เปิด http://localhost:5173 (หรือ Live Server ของ VS Code)

### 3. ขึ้นเว็บด้วย Vercel
1. push โค้ดขึ้น GitHub
2. https://vercel.com → Add New → Project → Import repo → Framework = **Other** (ไม่ต้อง build) → Deploy
3. Supabase → Authentication → URL Configuration → ใส่โดเมน Vercel ใน **Site URL**

`vercel.json` ตั้ง URL สวย (`/host`, `/menu`, `/kitchen`, `/cashier`), security headers และ cache ให้แล้ว

## ทดสอบฐานข้อมูล

มีชุดทดสอบที่รัน `schema.sql` กับ PostgreSQL จริง (ดาวน์โหลดมารันชั่วคราวในเครื่อง ไม่แตะฐานข้อมูลจริง)
แล้วจำลองทั้งรอบ: เปิดโต๊ะ → ลูกค้าสั่ง → ครัว → เรียกเก็บเงิน → ปิดบิล → รายงาน → ข้อความ Telegram

```
npm install
npm test
```

ครอบคลุม 29 เคส รวมถึงกรณีที่ต้อง**ล้มเหลว**: เปิดโต๊ะซ้ำ · token ปลอม · สั่งเมนูที่ของหมด ·
สั่งเพิ่มหลังเรียกเก็บเงิน · จ่ายเงินไม่ครบ · ใช้ QR เดิมหลังปิดบิล

## สิ่งที่ควรทำต่อถ้าใช้งานจริง

1. ต่อระบบชำระเงินออนไลน์ (PromptPay QR แบบไดนามิก / Omise / GB Prime Pay) ให้ลูกค้าจ่ายเองจากมือถือ
2. เปลี่ยนรูป SVG เป็นรูปถ่ายจริง (อัปโหลดได้จากหลังบ้าน → เก็บใน Supabase Storage)
3. พิมพ์ใบเสร็จผ่านเครื่องพิมพ์ความร้อน 80 มม. (หน้าเว็บรองรับ `window.print()` แล้ว)
4. เพิ่มระบบสมาชิก/สะสมแต้ม และรายงานกำไรต่อเมนู (มี view `v_item_sales` รอไว้แล้ว)
